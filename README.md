# DECIVANTA

DECIVANTA is an autonomous executive intelligence project being developed for the CockroachDB AI Hackathon.

The implementation will begin after the approved Scope, PRD, Technical Specification, and Build Checklist are received.

## Status

Hackathon MVP build in progress. The first sponsor-integration spike proves a bounded AWS Lambda to CockroachDB Cloud Managed MCP read contract without accepting browser-controlled SQL.
